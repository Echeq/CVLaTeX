# Demo script — 2 to 3 minutes

A shot list for the competition video. Record at 1080p or higher, keep the
cursor visible and avoid showing personal data.

**Reference short cut:** [demo player](https://echeq.github.io/CVLaTeX/demo.html)
(45 s, current build). Use it as a timing/style reference; the full competition
video can follow the timing below.

**Target length:** 2:30–3:00.

## 0:00–0:20 — Problem

- Show a LaTeX editor or a blank document for a second.
- Voice-over: “Making a professional CV in LaTeX is powerful, but most
  students do not want to learn LaTeX, install a TeX distribution or upload
  their personal data to a website.”
- Cut to the CVLaTeX main window.


## 0:20–0:50 — First run and form

- Show the language picker (English / Español / 中文 / Русский).
- Load the sample CV.
- Type a name and one achievement; the preview updates.
- Mention: **offline, no account, no cloud**.


## 0:50–1:30 — Templates and markets

- Switch between Classic, Harvard, Modern and a Chinese template.
- Show the Chinese CV compiled with XeLaTeX.
- Mention the 12 templates and the market guides
  (`Help → Dedicated to each market`).
- Show A4/Letter and serif/sans/monospace controls in Settings.


## 1:30–2:05 — Export

- Export to PDF.
- Export to Word (no LaTeX required).
- Open the exported `.tex` and show the embedded data block.
- Mention the lossless `.tex` round-trip: export, edit, import.


## 2:05–2:30 — Quality and closing

- Show `File → Settings`, the 1032-test suite and the three-OS CI.
- Mention MIT license, offline privacy and the TinyTeX on-demand installer.
- Close on the logo and the repository URL.


## Shot list

| Scene | Screen | Duration |
| --- | --- | --- |
| Problem | LaTeX editor / blank page | 20 s |
| First run | Language picker + sample | 30 s |
| Templates | Four templates + Chinese PDF | 40 s |
| Exports | PDF, Word, `.tex` | 35 s |
| Quality | Tests + CI + credits | 25 s |

## Capture notes

- Use a clean user profile or hide personal files.
- Close notifications and unrelated browser tabs.
- Use the English UI for the international cut; record a Chinese or Spanish
  cut if the jury prefers it.
- Keep the mouse movement deliberate and slow.
- Add English subtitles; the competition audience may include non-Spanish
  speakers.
- Export H.264 MP4, 1080p, 30 fps. If the file is larger than 50 MB, host it
  on YouTube/Bilibili and link it instead of committing it.
