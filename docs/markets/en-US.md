# United States — resume guide (en-US)

**Market snapshot:** US employers expect a short, reverse-chronological
**resume**, usually one page early in a career and two pages at most. Photos,
age, date of birth, marital status and nationality are left out. Large
employers screen with applicant tracking systems (ATS), so plain structure and
job-specific keywords matter.

Last reviewed: 2026-11-19.

## At a glance

| Item | Recommendation |
| --- | --- |
| Document | Resume (not an academic CV) |
| Length | 1 page early career; 2 pages maximum |
| Paper | US Letter (8.5 × 11 in) |
| Photo | No |
| Personal data | No age, date of birth, marital status or nationality |
| Order | Reverse chronological |
| File | Text-selectable PDF, or .docx when the posting asks for it |
| Language | English (US spelling) |

## Sections and order

1. **Contact** — name, city and state, phone, professional email, LinkedIn
   and a portfolio/GitHub when relevant.
2. **Summary** — optional; two or three lines tailored to the target role.
3. **Experience** — reverse chronological; employer, title, location, dates,
   and 3–5 achievement bullets per role.
4. **Skills** — hard skills and tools, grouped and easy to scan.
5. **Education** — degree, institution, graduation date; GPA only if strong
   and recent.
6. **Projects / certifications** — valuable for students and career changers.

For a first job, lead with **Education**, then projects, internships, campus
work and volunteering. The one-page rule is a convention, not a law: add a
second page only when the extra evidence is relevant.

## Photo and personal data

Do not add a photo. US employers are cautious about receiving photos because
of anti-discrimination rules, and most ATS discard images during parsing. Omit
age, date of birth, marital status, nationality, religion, health and a Social
Security Number. A city and state are enough; a full street address is not
needed.

## ATS and file format

- Use standard headings: Summary, Experience, Skills, Education.
- Prefer a single-column layout without tables, text boxes or graphics.
- Mirror the job posting's job title, tools and keywords naturally.
- Quantify results: “cut onboarding time by 30%”, not “responsible for
  onboarding”.
- Send a text-selectable PDF unless the posting asks for .docx.
- Name the file `Firstname_Lastname_Resume.pdf`.

## Common mistakes

- A photo, age or marital status.
- A two-column “creative” layout that an ATS cannot parse.
- Long paragraphs instead of bullets.
- Generic duties without numbers or outcomes.
- Listing references or writing “references available on request”.
- Using A4 for a US employer; US Letter is the local default.

## CVLaTeX settings

- Template: **Classic**, **Harvard** or **Modern** (ATS-friendly families).
- Paper: **US Letter**.
- Font size: **10–12 pt**; font style: template default or sans.
- CV language: **English**.
- Photo and school logo: leave empty.
- Export: **PDF** (or Word when requested).
